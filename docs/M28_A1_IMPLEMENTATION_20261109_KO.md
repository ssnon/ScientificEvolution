# M28-A1 — 자율 연구 조직 선택의 최초 실행 통합

**기준 코드:** `c7a7bd1`, `dev/meta-research-autonomy-v1` (2026-11-09 KST)

**목적:** 실제 과학적 연구 판단이 연구 조직 변경의 실행으로 연결되게 한다. 최종적인 AI Scientist 아키텍처를 고정하는 설계가 아니라, A0 계약의 최초 수직 통합이다.

## 무엇을 구현했나

- 기존 Controller는 일반 Work와 더불어 **선택적** `organization_requests`를 같은 저장된 모델 응답으로 반환할 수 있다. 새로운 상위 Meta-Controller나 별도 평가 호출을 의무로 추가하지 않는다.
- `META_RESEARCH_AUTONOMY_ACTIVATED` 정책이 활성화된 **새 ROOT만** 조직 변경을 허용한다. 이전 M26 및 Source-Pinned 연구 기록은 그대로다.
- `ORGANIZATION_REQUESTED`는 모델이 작성한 의도, `ORGANIZATION_ROOT_MATERIALIZED`는 실제 ROOT 초기화 사실이다. 어느 쪽도 과학적 결과·증명·논문 검증을 뜻하지 않는다.
- 자식 연구는 원래 P0만 받고 출발하는 맹검 독립 연구 또는 명시적인 기존 AI 주장에 대한 표적 독립 비판으로 생성된다. 표적 비판은 FRESH 원점 독립 연구로 표시하지 않는다.
- 진행 중인 부모 Work, 이전 계산, 모델 호출과 Journal은 단순히 새 연구자가 생겼다는 이유로 완료/취소/합성되지 않는다.
- 새 조직 실행기는 세대·PEER 수·합성 단계를 강제하지 않는다. 새 ROOT 생성은 결정의 결과이며, 그 이후 연구 수행과 합성은 별도 행동이다.
- staging/영수증/컨트롤러 응답 연결을 통해 결정과 생성의 인과 관계 및 재실행 시 중복 생성을 검증한다. 완료된 staging은 복구하지만, 불완전·손상된 staging은 추측으로 삭제하지 않는다.

## 기존에 있던 기능과 구분

`Engine`의 Problem/Work 생성, 실행 지속, 포트폴리오 KEEP/DEFER/CANCEL/REACTIVATE, FRESH 데이터 격리, 과학적 HOLD는 이미 있었다. 이를 다시 개발한 것이 아니다. 이번 추가의 범위는 기존 연구 결정이 **서로 다른 ROOT의 실제 조직 구성**을 직접 선택할 수 있게 하는 것이다.

## 확인해야 할 조건

A1 테스트는 실제 Journal·Controller와 모의 SAVED 모델 응답을 사용해 수행한다. 선택이 없으면 연구자가 추가되지 않는가, 부모 Work가 그대로 남는가, 맹검과 표적 독립의 정보 경계가 정확한가, 실제 ROOT 생성 영수증이 존재하는가, 반복 실행과 일부 크래시 복구가 안전한가, 비활성 레거시에서 조직 변경이 거부되는가를 확인한다.

이것은 과학적 판단의 **실행 가능성** 검증이지, 모델의 **과학적 선택 품질** 검증이 아니다. 또한 M26 원래 문제에 대한 완결이나 과학적 Level II 달성을 증명하지 않는다.

## 아직 수행하지 않은 것

- 독립 ROOT 간 과학적 결과의 선택적 전달·비판·합성 (A2).
- 전역 포트폴리오의 HOLD/완료와 개별 ROOT의 HOLD를 연결하는 판단 (A2).
- 여러 ROOT의 외부 동시 실행, 모든 유형의 중간 크래시 원자적 회복과 기존 전체 회귀 검증 (A3).
- 실제 유료 모델의 조직 선택과 그 과학적 유익성 실험 (A4; 별도 승인 필요).

**운영 상한**(호출, ROOT 수, 동시 실행)은 연구자 수를 과학적으로 지정한 것이 아니다. 과학적 연구 방법·협력·종료는 시스템의 자율적인 판단 범위로 남긴다.
