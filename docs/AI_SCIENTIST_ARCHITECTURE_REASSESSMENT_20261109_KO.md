**기록일:** 2026-11-09 (KST)  
**성격:** 설계 요구조건 정정 + M26/M27 증거의 통합 해석 + 차기 구조 검토 기준  
**상태:** 문서상의 설계 기준 수립. **새 아키텍처 구현·실험 검증·과학적 성과를 주장하지 않음.**  
**참조:** `PROJECT_VISION.md`, `DEVELOPMENT_STATE.md`, `RESEARCH_EVOLUTION_LOG.md`, M26/M27 원본 read-only 감사 자료.  
**프로젝트의 궁극적 목표:** 특정 SERS 문제나 FAKG/KG 시스템이 아닌 **범용 자율 AI Scientist**.

## 1. 최초 구상의 핵심 — 이번 대화에서 명시적으로 바로잡은 사항

인간은 미해결 과학 문제(P0)와 허용되는 실제 자원·안전 경계를 제공한다. **연구 조직과 과학적 절차 자체도 AI Scientist의 자율적 판단 대상**이다. 사람은 연구자 수, 독립 연구 횟수, 합성 시점, Population의 크기, 다음 세대의 존재 및 횟수를 과학적 정책으로 미리 정하지 않는다.

시스템은 과학적 필요에 따라 (a) 한 연구자가 계속 수행, (b) 여러 독립 연구자의 동시/순차 탐색, (c) 비판·독립 재현·수학 검증, (d) 협력과 결과 합성, (e) 연구 방향의 분기·전환, (f) 추가 연구 집단/세대의 구성 또는 생략 중 적합한 방식을 결정한다. 어떤 방식도 의무 단계가 아니며, 그 선택이 과학적으로 더 나은 결과를 보장한다고 미리 가정하지 않는다.

연구가 원리적으로 비식별적이거나 필요한 관측/자료가 없거나, 현재 가능한 연구 행동의 예상 가치가 충분하지 않다는 판단이 **근거에 의해 정당화될 때**, 시스템은 스스로 연구를 HOLD·보류·종결할 수 있어야 한다. 반대로 단순한 접근 오류, 연구자 실패 또는 계산이 어려웠다는 사정만으로 불가능성을 선언하면 안 된다. 과학적 중단과 외부 호출 예산·시간·권한에 따른 **운영상 일시정지**는 철저히 구분한다.

여기서 자율성에는 두 측면이 있다.

- **과학적 자율성:** 무엇을 묻고 연구하며, 어떤 방법·근거·결론이 합리적인지 결정한다.
- **메타 연구 자율성:** 몇 명의 연구자를 사용하고 어떤 역할을 맡기며, 언제 비판·합성·재구성·지속·중단할지 결정한다.

이는 무제한의 외부 권한이나 비용을 부여한다는 뜻이 아니다. 사람의 보안·비용·승인 상한은 운영 경계로 유지하되 **과학적 선택 규칙**과 혼동하지 않는다.

## 2. 시스템이 갖춰야 할 능력 — 고정 단계가 아님

다음은 강제 순서가 아니라 상황에 따라 호출할 수 있는 역량이다.

1. **문제 이해·정식화·해결 가능성 평가:** 관측·가정·경쟁 설명을 파악하고, 현재 조건의 식별가능성 및 필요한 추가 정보를 구분한다.
2. **자율 연구 전략:** 가치, 실행 가능성, 정보 획득 가능성을 비교해 연구 문제·방법·도구·협업 형식을 스스로 선택한다.
3. **실제 연구 수행:** 수학적 증명/반례, 계산, 문헌 원문 점검, 실험/측정 설계 등을 재현 가능한 결과로 수행한다. 계획과 수행 결과를 구분한다.
4. **비판·검증·자기수정:** 주장과 실제 근거의 구분, 강한 Null과의 비교, 오류 검출, 범위 제한, 수정/철회가 가능하다.
5. **지속성과 과학적 계승:** 코드·자료·실패·가정·미해결 전제를 다음 행동에 반영한다. 역사적 접근 가능성과 실제 과학적 활용은 다르다.
6. **조직의 자율적 재구성:** 동료·검증자·Population·세대의 필요성을 판단하고 생성·생략·합성·해체할 수 있다.
7. **근거 기반 결론·HOLD:** 해결, 조건부 후보, 제한적 부정, 비식별성, 증거 부족 및 정당한 중단을 구분한다. 반드시 긍정적 발견으로 끝날 필요는 없다.

위 항목을 `Controller`, `Worker`, `PEER`, `Generation` 같은 현재의 클래스나 계층과 동일시하지 않는다. 그 역할을 어떤 구조로 구현할지 자체가 평가 대상이다.

## 3. M16–M27에서 확인한 증거와 그 의미

### 기존에 해결·검증한 사항 — 재발견하지 말 것

- M16–M18: 원본 연구·Work·거부/실패 상태의 구분과 연구 계보 전송을 강화했다.
- M19–M20: INFORMED 연구의 과거 source catalog 및 조회 기능을 강화했다.
- M23.4–M23.6.2: 실제 계산 관측과 `PLAN_ONLY` 구분, 출처·부모 관계, 원본 도구 결과의 역사적 계승을 다뤘다.
- M25: 실제 G1 계승 감사에서 716개 과학 자산 및 9개 기존 과학 도구 기록의 보존을 확인했다. `PLAN_ONLY` 분류 오류 두 건을 수정했지만 이로써 후속 연구자의 과학적 활용이 입증된 것은 아니다.
- M26: 원본 SAVED Worker I/O, Controller 판단, 계산·문헌 도구 결과를 이미 장시간 분석했다. 같은 입력 전달/실행 원인 조사를 이름만 바꿔 반복하지 않는다.
- M27: 좁게 정의한 CTMC 수치 과제에서는 정확한 실행 가능 코드를 만들었으나, 한 응답에는 복수 JSON root가 있었고 Native Worker의 직접 정상 실행으로 볼 수 없다. 제한 과제 성공은 장기 자율 연구 능력의 증명이 아니다.

### M26의 통합 자율 연구 결과 (현 상태의 가장 중요한 사례)

- 2개 세대, 6개 연구 ROOT, **192 SAVED 모델 호출 / 25 Controller 결정**. 명시된 호출 경계에서 운영 종료. P0는 `UNRESOLVED`, disposition은 `ONGOING`.
- 100회 Controller 및 NVT/PMI/Opportunity 평가, 63회 일반 연구 Worker, 29회 Native Math Worker 호출. **이 숫자는 운영상의 구성이지 과학적 능력의 직접적인 점수가 아니다.** 호출을 더 허용하면 달라질 수 있는지 반사실적으로 미확정이다.
- 실제 단일 노출 CTMC–Poisson PMF 계산의 오류 수정과 수치적 검증, 다중 채널 모형의 조건부 식별성·비식별성 결과, 기작 가설과 반례/수학적 비판은 과학적 성과다.
- 전체 시간 결합 likelihood, 물리적으로 제한된 강한 Null 비교, 실제 held-out 분리, 원문 실험 근거 확보, 외부 독립 검토가 가능한 Level II 제안의 완결은 **입증되지 않았다**.
- 독립 PEER 자산의 기록상 합병은 있었으나 해당 세대의 새 PEER 자산을 직접 부모로 삼는 Population Work는 관찰되지 않았다. 이것만으로 간접 활용이나 합성 가치의 부재를 단정하지 않는다.
- 최종 G1 Controller 결정과 나중에 기록된 수정 PMF 결과의 시간 순서를 보존한다. 이후 결과를 이전 Controller가 무시했다고 주장하지 않는다.

### 발견된 '설계상 불일치'와 아직 미확인인 '성능 병목'

**확인된 불일치:** 현 `persistent_population.py`에는 외부 `peer_count`, `max_cycles`, PEERS → COMBINE → POPULATION 실행 경로가 존재한다. Controller의 연구 Work 선택은 자율적이어도 **연구자 수·세대/합성 여부 자체가 과학적 필요에 따라 동적으로 결정되는 원래 목표**는 충분히 구현되지 않았다. 기존 시스템에는 과학적 HOLD 지원이 있지만 M26에서는 자율 과학적 종료가 관찰되지 않고 운영 경계에서 멈췄다.

**미확인 인과:** 이 메타 자율성 부족이 M26의 미완료를 유발했다는 증거는 없다. 모델의 연구 정식화·장기 계획·실행 능력, 도구 작업 공간, 자료의 부재, 과제 자체의 비식별성, 연구 조직 방식은 상호작용하는 후보 원인이다. 동적 연구자 수를 도입한다고 수학적·과학적 능력이 자동 향상되지는 않는다.

## 4. 이전 설계 검토가 반복된 이유와 반성

최근 논의에서는 Worker 실행 → 연구 계승 → 세대 구조 → 평가 호출 비용 → 정보 증가/전략 적응으로 병목의 중심을 반복해 이동했다. 각 진단은 일부 사실을 밝혔지만 **마지막으로 관찰한 현상을 전체 실패의 원인처럼 취급**하는 위험이 있었다. 이미 존재하는 구현을 새로운 기능으로 재제안했고, M26 로그를 다른 이름으로 다시 감사할 뻔했다. 대안인 '지속적 Research Program'조차 기존 Work와 실질적으로 어떻게 다른지 입증하지 못했다.

특히 호출 비용을 아끼는 것은 운영 효율이며 장기 자율 연구의 본질적 성공과 구분한다. 예산을 늘리면 해결되는 실행 부족과, 예산을 늘려도 반복되는 잘못된 연구 판단/비식별성은 다르다. NVT/PMI의 빈번한 `UNCHANGED` 자체를 연구 무진전의 증거로 삼지 않는다.

## 5. 현재 아키텍처를 가설로 두고 검토할 범위

| 차원 | 검토 질문 | 결론의 현재 상태 |
|---|---|---|
| 연구 목표·정식화 | 무엇이 현재 조건에서 답할 수 있는 질문인가? | 일부 비식별성 논증만 확인 |
| 연구 전략 선택 | 가치·실행 가능성·증거 요구를 비교하는가? | 선택은 있었으나 체계적 품질 미확정 |
| 실제 실행 | 선택한 계산·증명·자료 검증을 지속 수행하는가? | 부분 성과, 복잡한 통합 Work 미완료 |
| 검증·자기수정 | 비판이 실제 주장과 다음 연구를 바꾸는가? | 국소적 수학 수정 확인 |
| 연구 조직과 메타 자율성 | 연구자 수, 역할, 합성, 세대, 스스로의 구성 방식을 선택하는가? | 고정된 기본 주기와 원래 목표의 불일치 확인 |
| 과학적 중단 | 충분한 결과·정당한 부정·자료 부족을 근거로 스스로 멈추는가? | 기능상 가능하나 M26에서 실증 미확인 |
| 인식론적 무결성 | 실제 실행과 모델의 주장, 출처와 계보가 구분되는가? | 기존 성과를 보존해야 함 |

이 표는 새 개발 순서나 의무 단계가 아니다. 상호작용하는 모든 근거를 함께 검토하기 위한 범위다.

## 6. 설계·개발 의사결정 규칙

1. **기존 구조를 보존하거나 폐기한다는 전제를 두지 않는다.** FRESH, PEER, Population, Generation, Controller, Asset DAG는 수단이다. 이미 검증한 무결성과 과학적 행동을 잃지 않는 범위에서 구조는 재설계할 수 있다.
2. **제약과 능력을 분리한다.** 새로운 선택지(동적 연구자 수)가 생겼다고 그 선택을 잘 한다고 가정하지 않는다. 판단 능력과 실제 실행 능력을 별도로 검토한다.
3. **문제 수준에서 평가한다.** 단일 Worker 코드/JSON 또는 호출 횟수만으로 전체 시스템 성공/실패를 정의하지 않는다. 정당한 제한적 부정·HOLD도 유효한 과학 결과다.
4. **새 진단은 기존 M26/M27 증거로 답할 수 없는 구별을 제공해야 한다.** 동일한 원본 I/O와 Controller 감사 반복 금지. 새로 얻을 정보가 어떤 설계 선택을 바꾸는지 명시한다.
5. **재설계는 실제 능력 차이를 설명해야 한다.** `Research Program`과 `Work`의 이름만 바꾸는 리팩터링, 메타 Controller 추가, 강제 단계·인위적 연구 quota 금지.
6. **운영 제약은 명시적으로 보존한다.** 비용/보안 승인과 과학적 판단을 분리하고, 외부 유료 호출은 별도 사용자 승인 없이는 실행하지 않는다.
7. **과학 기록은 불변이다.** 이전 Journals, Provider 응답, Tool 결과, 실패/부정 사례, 계보를 수정하거나 실험 성공으로 재해석하지 않는다.
8. **구조의 실질적 기여를 물어야 한다.** 단일 연구자보다 다중 연구 집단이 어떤 새로운 과학적 비판·증거·실행 능력을 실제로 창출하는지 비교한다. 단일 연구자가 필수라는 역방향 가정도 하지 않는다.

## 7. 다음 단계 — 이미 결정된 것과 아직 결정하지 않은 것

**지금 확정된 것:** 원래 목표의 메타 연구 자율성 요구조건을 프로젝트 비전에 명시한다. 현 고정 PEER/세대/Population 프로토콜을 보편적인 AI Scientist의 정의로 간주하지 않는다. 연구자가 근거에 따라 자율적으로 HOLD/중단할 권한과 능력을 평가한다. 과학적 무결성, 실패 및 원본 보존을 유지한다.

**아직 결정하지 않은 것:** 중앙 Controller 제거 여부, 연구자/평가자 역할 동적 생성의 정확한 API, 세대 기반 구현의 폐지 여부, 지속적 코드 작업 공간의 형태, 새로운 메타 정책, 기존 평가 연쇄의 대체 방식, 새로운 유료 실험 설계. 이를 현재 결론인 양 기록하지 않는다.

**다음 설계 작업의 산출물:** (a) 현재 런타임이 허용·차단하는 과학적/메타 연구 선택지 표, (b) 원래 목표에 필요한 선택지의 최소 충분한 표현, (c) 기존 구현 대비 **실질적 능력 차이**와 보존할 무결성 명세, (d) 검증되지 않은 인과 가설과 향후 비교 가능한 관찰. 이 작업이 완료되기 전에는 M27 코드 패치 또는 재실행을 성급히 시작하지 않는다.

**종합 판단:** M26은 부분적으로 유능한 자율 연구의 실제 증거이자, 통합 과학 문제의 미완료 사례다. 현 구조가 최초 구상한 메타 연구 자율성을 완전히 구현하지 않았다는 것은 확인 가능한 설계상의 차이지만, 그것이 M26의 과학적 미완료 원인이라는 주장은 미검증이다. 목표는 비용 절약이나 고정 Population의 유지가 아니라 **문제·방법·연구 조직·검증·지속/중단을 과학적 근거로 스스로 판단하고 실제 연구를 수행하는 범용 AI Scientist**다.
